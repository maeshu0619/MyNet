 General
 -------
        --mode=0                        The encoding/decoding mode:
                                          0: encode
                                          1: decode
        --firstFrameNum=0               Frame number for use with
                                        interpolating %d format specifiers in
                                        input/output filenames
        --frameCount=1                  Number of frames to encode
        --reconstructedDataPath=""      The ouput reconstructed pointcloud
                                        file path (decoder only)
        --uncompressedDataPath=""       The input pointcloud file path
        --compressedStreamPath=""       The compressed bitstream path
                                        (encoder=output, decoder=input)
        --postRecolorPath=""            Recolored pointcloud file path
                                        (encoder only)
        --preInvScalePath=""            Pre inverse scaled pointcloud file
                                        path (decoder only)
        --convertPlyColourspace=1       Convert ply colourspace according to
                                        attribute colourMatrix
        --outputBinaryPly=1             Output ply files using binary (or
                                        ascii) format
        --outputUnitLength=0            Length of reconstructed point cloud x,y,z unit vectors
                                         0: use srcUnitLength
        --outputScaling=1 (External)    Output coordnate system scaling
                                         0: Conformance
                                         1: External
        --outputPrecisionBits=-1        Fractional bits in conformance output (prior to external scaling)
                                         0: integer,  -1: automatic (full)

 Coordinate system scaling
 -------------------------
        --srcUnitLength=1               Length of source point cloud x,y,z
                                        unit vectors in srcUnits
        --srcUnit=0 (Dimensionless)      0: dimensionless
                                         1: metres
        --inputScale=1                  Scale input while reading src ply. Eg,
                                        1000 converts metres to integer
                                        millimetres
        --codingScale=1                 Scale used to represent coded
                                        geometry. Relative to inputScale
        --sequenceScale=1               Scale used to obtain sequence
                                        coordinate system. Relative to
                                        inputScale
        --positionQuantizationScale=1   (deprecated)
        --externalScale=1               Scale used to define external coordinate system.
                                        Meaningless when srcUnit = metres
                                          0: Use srcUnitLength
                                         >0: Relative to inputScale

 Decoder
 -------
        --skipOctreeLayers=0            Partial decoding of octree and attributes
                                         0   : Full decode
                                         N>0 : Skip the bottom N layers in
                                        decoding process
        --decodeMaxPoints=0             Partially decode up to N points
